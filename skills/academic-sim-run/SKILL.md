# 论文仿真

跑 MATLAB 仿真、改 `.m`、出图时用。本技能只管**产出是代码、结果文件、图**的工作。

## 什么时候加载

- 跑仿真、改仿真脚本、重写出图代码
- 换机器跑、打包交接
- 图和正文对不上，需要确认哪份结果是真的

改论文文字 → `academic-voice`；整篇审稿 → `academic-audit`。

## 四条底线

1. **先方案后动手**：改 `.m` 前给方案，说清改哪个文件、改哪段、预期结果如何变。
2. **不写死盘符**：MATLAB、CVX、数据目录、结果目录全部运行时探测，探测结果必须打印出来。
3. **无人值守**：长跑不许中途停下来等确认，跑完自己保存、自己报路径、自己结束。
4. **正式结果就是正式结果**：主稿里图对应的代码和 `.fig` 是基线，改动后要能和它对上号。

## 规则正文

| 要做什么 | 读 `references/sim-rules.md` |
| --- | --- |
| 代码形态、命名、注释 | 20.1 |
| 运行方式、并行池、检查点、无人值守 | 20.2 |
| 换电脑、打包、CVX 与路径探测 | 20.3 |
| 出图、`.fig` 改图、PDF 规格 | 20.4 |

| 结果与论文的对应关系 | 20.6 |

## 交付格式

```markdown
## 仿真报告

- 脚本：<文件>（本次是否修改）
- 环境：MATLAB <版本> @ <探测到的路径>；并行池 <N> workers；CVX <版本>
- 结果目录：<路径>（新增/沿用）
- 产物：MAT、CSV、TXT、FIG、PNG、PDF（缺哪个说明原因）
- 与基线差异：<无 / 具体差异>
- 下一步：<需要人工确认的点>
```

跑完只报这些，不贴长日志。日志落盘，路径写进报告。
