# 面试复盘字段模板

## 来源标记

| 标记 | 含义 |
| --- | --- |
| `[录音原文]` | 从录音或原始转写直接得到的内容 |
| `[用户补充]` | 用户在复盘时补充的现场信息 |
| `[背景资料]` | 简历、项目文档或既有备书中的内容 |
| `[复盘分析]` | 对回答质量、逻辑和岗位匹配的分析 |
| `[建议表达]` | 不是原回答，用于下一次练习 |
| `[待确认]` | 当前材料不足以确认的内容 |

## 逐题原话与复盘字段

```text
问题编号与时间：
问题类型：
面试官原话：[录音原文]
候选人原话：[录音原文]
追问与面试官反馈：[录音原文]
回答总结：[复盘分析]
考察点：[复盘分析]
回答评价：[复盘分析]
事实依据与待确认项：
建议表达：[建议表达]
可能追问：[复盘分析]
```

## 反问记录字段

```text
候选人原反问：[录音原文]
面试官原回答：[录音原文]
问题价值：[复盘分析]
风险与改进：[复盘分析]
更合适的问法：[建议表达]
```

## 完整性检查

- [ ] 每题都有面试官原话、候选人原话、追问与面试官反馈
- [ ] 原话未被概括、润色或替换成“回答要点”
- [ ] `[听不清]`、`[术语待确认]` 等不确定标记保留
- [ ] 文末附完整连续 ASR 原文，或给出可追溯的附件链接与位置说明
- [ ] 建议表达与录音原话明确分开

## 完整转写附录字段

```text
转写来源：
录音时长/时间范围：
说话人分离：有 / 无（按上下文切分）
时间戳：有 / 无
附件路径与原文位置：
识别限制或未覆盖片段：
```

## 文档顺序

```text
记录信息
问题大纲
逐题原话与复盘对照
反问环节原话与复盘
总体结论
复习行动清单
完整连续 ASR 原文附录
```
