# 面试复盘字段模板

## 来源标记

| 标记 | 含义 |
| --- | --- |
| `[录音原文]` | 从录音或原始转写直接得到的内容 |
| `[用户补充]` | 用户在复盘时补充的现场信息 |
| `[背景资料]` | 简历、项目文档或既有备书中的内容 |
| `[复盘分析]` | 对回答质量、逻辑和岗位匹配的分析 |
| `[建议表达]` | 不是原回答，用于下一次练习 |
| `[待确认]` | 当前材料不足以确认的内容 |

## 逐题记录字段

```text
问题编号与时间：
问题类型：
面试官问题：[录音原文]
候选人原回答：[录音原文]
追问与反馈：[录音原文]
考察点：[复盘分析]
回答评价：[复盘分析]
事实依据：
建议表达：[建议表达]
下一步追问：
```

## 反问记录字段

```text
候选人反问：[录音原文]
面试官回答：[录音原文]
问题目的：[复盘分析]
有效性与风险：[复盘分析]
更合适的问法：[建议表达]
```
