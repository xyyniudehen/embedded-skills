# 学术写作

改英文正文时用。本技能只管**产出是句子、段落、图题、公式**的工作。

## 什么时候加载

- 改一句、一段、摘要、结论、贡献列表
- 文献回顾怎么写、怎么衔接、怎么编号
- 图题、坐标轴命名、公式排版、篇幅（页数）
- 自查用词和句式是否像用户自己写的

要跑代码或改 `.m` → 用 `academic-sim-run`；要整篇审稿 → 用 `academic-audit`。

## 一、先看锚点，再看这一篇自己的写法

1. 读方向锚点（见 `academic.md`）：研究问题、贡献、页数、禁写清单。
2. 读目标论文**已有的正文**，找到用户自己写的段落作基准。**以这篇的实际写法为准，不以本技能的理想写法为准**。本技能里的规则若与稿子现状冲突，指出冲突，不擅自统一。

## 二、改之前

- 门禁与方案要素见 `global/academic.md` 的「硬门禁」；这里只强调一点：方案必须带**改前/改后**对照。
- 只改用户点名的地方。顺带发现的别处问题列成清单，不一起改。
- 涉及术语、缩写、符号统一时，先声明「这是全局替换」，确认后全文同步，禁止只改一处留下两套定义。

## 三、规则正文

按需读，不要整篇背诵：

| 要做什么 | 读 `references/writing-rules.md` |
| --- | --- |
| 选词、禁用词、句式、标点 | 10.1 |
| 段落逻辑、承接、摘要、引言 | 10.2 |
| 文献回顾与引用格式 | 10.3 |
| 缩写、术语、符号一致性 | 10.4 |
| 图表标题、坐标轴、图之间呼应 | 10.5 |
| 公式排版与约束分组 | 10.6 |
| 篇幅（页数）控制 | 10.7 |

每条规则末尾的 `[证据 Xnn]` 指向 `references/evidence.md`，那里有原始会话和原话。只在被质疑规则来源时才读。

## 四、交付格式

```markdown
## 改动方案

| # | 位置 | 改前 | 改后 | 依据 |
| --- | --- | --- | --- | --- |
| 1 | 引言第二段第 3 句 | ... | ... | 10.3 文献不带人名 |

影响：页数 +2 行 / 全局替换 3 处 / 只改本段
```

改完后补一句核对：全文字数或页数变化、是否触发全局替换、哪些地方**没改**。
